## 개요

직관 마찰손실 외에 밸브·엘보 등 부속에서 생기는 손실. 계산법은 두 가지다.

## 방법 A — K값(저항계수)법

$$
h_L = K \cdot \frac{v^2}{2g}
$$

대표 K값:

| 부속 | K값 |
| --- | --- |
| 90° 엘보 (LR) | 0.3 |
| 90° 엘보 (SR) | 0.75 |
| 45° 엘보 | 0.35 |
| Tee (직진) | 0.4 |
| Tee (분기) | 1.0 |
| 게이트 밸브 (전개) | 0.15 |
| 글로브 밸브 (전개) | 6.0 |
| 체크 밸브 (스윙) | 2.0 |
| 버터플라이 밸브 | 0.5~1.5 |
| 스트레이너 | 1.5~3.0 |
| 입구(돌출) / 출구 | 1.0 / 1.0 |

(출처 기준: Crane TP-410을 메인으로, HVAC 보조 데이터는 ASHRAE Handbook)

## 방법 B — 등가길이법

각 부속을 등가직관길이($L_e$)로 환산해 직관 길이에 더한 후 일괄 계산한다.

## 장비 압력강하

열교환기·필터·유량계·컨트롤 밸브 등은 **제조사 데이터시트의 $\Delta P$ 곡선을 그대로 입력. 추정 금지.** 특히 컨트롤 밸브는 $\Delta P$가 양정의 큰 부분을 차지하므로 주의한다.
